# Demo project (synthetic)
Fictional checkout app used by the analyzer demo. `../logs/production_sample.log` is generated by
`python scripts/generate_demo_log.py`, which looks up the real line numbers in `src/`. Not real production data.
Scenario: DB pool exhaustion -> `DatabaseConnectionTimeout` in `PaymentService.charge` -> `CheckoutError`
(HTTP 500). A rarer, unrelated `KeyError: 'currency'` is also included as a second incident.
